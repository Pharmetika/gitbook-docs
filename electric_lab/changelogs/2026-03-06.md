# 2026-03-06

## Enhancements

* Inventory Reordering: Added the ability to base reorder points for compound formulas on the day supply instead of a set quantity. This allows users to base reorders on a usage over time metric. For example, a user could set the reorder point to align with “30 days of average usage”.&#x20;
* Stations: Stations are now created and configured separately from other equipment.&#x20;

Additionally, a “Station Capacity Points” field has been added to designate the maximum number of task points a station can accommodate each day.&#x20;

**Reports**

* Added the “Capacity Planning Report”, which shows all queued points for each station against each station's known capacity, allowing users to predict and plan usage accordingly.&#x20;
* Added the “Lots by Date Removed” report, which shows lots removed from inventory based on the removal date.&#x20;
* Added the “Pending Lot Inventory Allocation” report, which shows ingredients that are currently in use for compounded lots that have not yet been approved.&#x20;
