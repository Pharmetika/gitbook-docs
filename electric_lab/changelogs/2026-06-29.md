# 2026-06-29

## Enhancements

**User Route Tracking:**

* Added user tracking functionality to ElectricLab, allowing users to see which accounts are currently viewing any given page or task. Users will now see a consistent icon on the top right of the screen; simply mouse over the icon to display all user account names actively accessing the page you are on.

**Unit Dose Label Templates:**

* The Unit Dose Label Options page now includes new “Template Style” options and a visual label preview image that updates in real-time as users make label option changes.
* The new “Template Style” options are an expansion of what was previously grouped under the “Template” options. We have separated these options into two categories, “Template Style” and “Template Size”, to better distinguish user choice and provide a more intuitive experience when creating labels. Additionally, we have added two new style options called “Banner” and “Minimal (right)”.
* The “Banner” label style is designed to provide a more sleek and stylish label while pronouncing bold color options for pharmacies that color code their products and want them to stand out. The “Minimal (right)” style reserves a white space, allowing pharmacies to incorporate pre-printed labels.This style will display the Barcode, Beyond Use Date, Date Compounded, and Lot Number on the right side while leaving the white space on the left for custom label contents.
* All previously available style and size options will now be found under the “Standard” style option.&#x20;
