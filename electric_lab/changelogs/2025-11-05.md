# 2025-11-05

## Enhancements

* Three new default lot label sizes are available:
  * 1.125 in X 3.5 in (29 mm X 89 mm)
  * 2 in X 4 in (51 mm X 102 mm)
  * 2.125 in X 2.725 in (54 mm X 69 mm)

To change your settings to use one of these new sizes, go to **Configuration > System Settings** and select from the dropdown menu in the **Label Dimensions** field. Note that this feature already appeared in production at the time this changelog was released.&#x20;
