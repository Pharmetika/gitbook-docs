# Upon Receiving an EPCS Token

{% hint style="info" %}
The Pharmetikator app can be downloaded utilizing the provided links within the email that was sent. Titled **Set up your Pharmetika Authenticator app**.
{% endhint %}

Once the token has been enabled and you've downloaded the app, log in using your Provider Portal credentials to begin electronically signing and submitting controlled substance prescriptions.

<figure><img src="../.gitbook/assets/Pharmetikator App.png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
You must **first login** to the app, and **enable** push notifications in order for the token to be registered before you start prescribing. **Please note:** The device used to initially register your soft token will be the only device authorized to electronically sign and authenticate controlled substance prescriptions.
{% endhint %}

## Sending Prescriptions From a Computer

The system will prompt you to authenticate your 2FA token. Click **Authenticate and Sign Prescriptions**.

<figure><img src="../.gitbook/assets/Authenticate &#x26; Sign (1).png" alt=""><figcaption></figcaption></figure>

After clicking Authenticate and Sign Prescriptions, the system will send a notification to the Pharmetikator soft token app.

<figure><img src="../.gitbook/assets/Soft Token Initiate Signing.png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/Soft Token Notification.png" alt=""><figcaption></figcaption></figure>

Open the Pharmetikator app to review orders pending approvals.

<figure><img src="../.gitbook/assets/Soft Token Pending Approvals.jpeg" alt=""><figcaption></figcaption></figure>

Tap on the order you wish to approve or deny.

<figure><img src="../.gitbook/assets/Soft Token Approve or Deny.jpeg" alt=""><figcaption></figcaption></figure>

**Approving Orders**: Click the <mark style="color:$success;">green</mark> _Approve_ button. The app will trigger a Success notification on the phone screen.

<figure><img src="../.gitbook/assets/Soft Token Order ApprovedSigned.jpeg" alt=""><figcaption></figcaption></figure>

While in the provider portal in the web browser, you will see that the screen updates to show that the prescription has been approved and submitted.

<figure><img src="../.gitbook/assets/Soft token order submitted.png" alt=""><figcaption></figcaption></figure>

**Denying Orders**: Click the <mark style="color:$danger;">red</mark> _Deny_ button. The app will trigger a Denied notification on the phone screen.

<figure><img src="../.gitbook/assets/Soft Token Order Denied.jpeg" alt=""><figcaption></figcaption></figure>

While in the provider portal in the web browser, you will see that the screen updates to show that the prescription has been denied.

<figure><img src="../.gitbook/assets/Soft Token Order Denied 2.png" alt=""><figcaption></figcaption></figure>
