# Adding a Driver's License

To add a driver's license to a patient, start by navigating to the patient's profile in your portal.

<figure><img src="../.gitbook/assets/image (76).png" alt=""><figcaption></figcaption></figure>

1. From here, click the Edit Demographics button (1)
2. Once the demographic editor is opened, scroll to the bottom to see the "Identity Information" section

<figure><img src="../.gitbook/assets/image (77).png" alt=""><figcaption></figcaption></figure>

3. Click the "+ Add" button to add a new identification document, and select the state driver's license you wish to add.

<figure><img src="../.gitbook/assets/image (78).png" alt=""><figcaption></figcaption></figure>

4. Once you've selected the type, entered the driver's license number, and an expiration date, click "Save Update" to save the driver's license.

<figure><img src="../.gitbook/assets/image (79).png" alt=""><figcaption></figcaption></figure>
