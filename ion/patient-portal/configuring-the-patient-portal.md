# Configuring the Patient Portal

You can configure several features in the Patient Portal to meet your pharmacy’s needs.

<figure><img src="../.gitbook/assets/Configure pp.png" alt=""><figcaption></figcaption></figure>

1. Select the **Enable Patient Portal Invites** checkbox to show the **Send Patient Portal Invite Email** button in the **Communication Preferences** section of the **Patient Profile**. Clear this checkbox to hide the button from the **Patient Profile**.
2. Select the **Allow Refill Request on Inactive Prescriptions** checkbox to let patients request refills for inactive prescriptions. When this checkbox is not selected, patients can’t select inactive prescriptions to request refills, and must contact the prescriber to make a refill request.
3. Select the **Allow Refill Request on Organization Pay Prescriptions** checkbox to let patients request refill for prescriptions billed to an organization instead of to the patient. When this checkbox is not selected, patients can’t select organization-pay prescriptions to request refills, and must contact the prescriber to make a refill request.
4. If you want to add a disclaimer to the registration page for the Patient Portal, enter the disclaimer in the **Registration Disclaimer** field.
