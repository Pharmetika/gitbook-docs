# Fill Request Queue

The **Fill Request Queue** shows fill requests for prescriptions that require pharmacist or technician input prior to filling. Currently, this queue is used for fill requests that can’t be completed because clinical screening needs to be reviewed, but we plan to expand use cases in the future. To access it, go to **Pharmacy > Fill Request Queue.**

<figure><img src="../.gitbook/assets/Fill Request Queue.png" alt=""><figcaption></figcaption></figure>

1. To filter by the date the fill request was submitted, enter a date range in the **Date Requested** fields.
2. To filter by a specific patient, enter the patient’s name in the **Patient** field.
3. To filter by a specific workflow requirement, select the requirement in the **Workflow Requirement** field. In the future, we plan to add more use cases, so this field will become more useful.
4. The **Rx/Fill #** column shows the prescription number and the fill number.
5. The **Patient** column shows the name of the patient.
6. The **Date Requested** column shows the date the fill request was submitted.
7. The **Workflow Requirements** column shows the type of fill request submitted. This column currently shows only the Clinical Screening value.
8. To remove a fill request from the queue without approving it, click the red X button.
