# 2025-07-16

## Enhancements

* To prevent alert fatigue and help streamline your pharmacy’s operations, a clinical screening window no longer appears if a pharmacist previously reviewed and approved the clinical screening and the patient’s clinical profile has not changed since that approval. If the pharmacist hasn’t approved the clinical screening previously, or if the patient’s clinical profile has changed since the last clinical screening approval, the technician can send the fill to the new **Fill Request Queue**, where a pharmacist can review the clinical screening information prior to dispensing the medication. For more information, [click here](../pharmacy/fill-request-queue.md).
* Contact information has a new, cleaner look in the **Patient Profile**. Now, you can add phone and fax numbers and email addresses using the **Edit Contact** window.

* The status of an invoice–Paid, Pending, or Cleared–now appears in the upper right corner of each invoice.
* A new API for clinics is available, which allows them to request a fill on a medication order they have previously sent. The **Fill Request API** allows the clinic to select the address, handoff method, priority, quantities, and provide notes. Utilizing this API can reduce the burden on the pharmacy and expedite processing. More information about this feature can be found in the Practitioner Portal API documentation. This API is currently available to pharmacies subscribed to an enterprise plan.
* In the Practitioner Portal, two new statuses now appear in the **Status History** section for prescriptions that appear in the **Recent Order Status** activity. The **Fill Reversed** status shows prescribers when a medication fill was reversed, and the **Fill Pending** status shows them when a fill is in-process.
