# 2025-07-30

## Enhancements

* When a pharmacy user scans a compounded lot into the Product Group Dispensing queue, the system now finds kit products for the linked product, and prompts the user to scan those items in. This feature helps make sure that kit products are dispensed correctly for compounded products.

## Fixes

* We’ve added some additional documentation around transferring controlled prescriptions, which can help answer pharmacists’ questions about why they can and cannot transfer prescriptions in certain scenarios. This fix doesn’t represent a change to the system itself, but it helps clarify some existing behavior that your pharmacists might not have understood. To see this documentation, click [here](../pharmacy/rx-entry-queue/new-prescription/transfers/).
