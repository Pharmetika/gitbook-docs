# 2025-08-29

## Fixes:

* We've made significant performance improvements to the **Prescription Entry Queue**.
* We've fixed an issue where addresses weren't appearing by default for filling. Now, when a pharmacy user enters an address in the **Address** field in the **Fill Options** section of the **Prescription Entry** activity, that address appears by default in the **Address** field during filling.
* The **Notify When Ready** checkbox now enables notification of a patient or organization when selected, as originally designed.
* For webhook registrations, an "email on failure" email address is now required.
